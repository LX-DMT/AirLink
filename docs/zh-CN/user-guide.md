# AirLink使用说明

## 1. 选择有线或无线模式

使用连接GPIOA_29的实体模式开关：

- **有线模式**：电脑直接使用USB Hub，圆屏提示HDMI、网口和耳机口可用；
- **无线模式**：Linux连接Wi-Fi，并通过VirtualHere把USB设备共享给同一局域网内的电脑。

切换模式后圆屏立即返回对应首页，网络服务在后台继续启动，不会阻塞触摸、
页面滑动和CH347控制。

## 2. 第一次手机配网

没有保存Wi-Fi配置时，AirLink会自动建立配网热点：

```text
热点名称：AirLink-XXXX
热点密码：12345678
门户地址：http://192.168.4.1/
```

操作步骤：

1. 将AirLink切到无线模式；
2. 手机连接`AirLink-XXXX`，密码输入`12345678`；
3. 手机通常会自动弹出配网页；没有弹出时，用浏览器访问
   `http://192.168.4.1/`；
4. 点击目标Wi-Fi，选中的网络会显示蓝色边框；
5. 输入目标Wi-Fi密码并点击“连接”；
6. 保持手机靠近设备，等待最多30秒的连接测试；
7. 配置保存成功后，圆屏自动返回Wi-Fi页面。

热点密码是固定产品策略。用户目标Wi-Fi密码不会进入C906L，也不会写入状态JSON、
诊断文件或日志。

### 重新配置与忘记Wi-Fi

在圆屏Wi-Fi页面点击“重新配置”可以重新打开热点信息页。点击热点信息窗口只会
关闭圆屏窗口，不会停止hostapd、dnsmasq或手机门户。需要彻底删除已保存网络时，
可在串口执行：

```bash
airlinkctl wifi forget
```

## 3. 使用VirtualHere

电脑安装VirtualHere官方客户端，然后：

1. 确保电脑和AirLink处于同一局域网；
2. 等待圆屏从“等待电脑连接”变为“电脑已连接”；
3. 在VirtualHere Client中展开AirLink服务器并选择要使用的USB设备。

AirLink监听TCP 7575。仅处于监听、电脑尚未连接是正常状态，不属于无线服务故障。
无法发现或连接时：

- 在VirtualHere Client中手工填写AirLink的IP；
- 关闭路由器的AP隔离、客户端隔离或访客网络隔离；
- 检查电脑防火墙是否允许VirtualHere；
- 如果路由器隔离2.4GHz客户端，可让电脑连接同一路由器的5GHz频段，但两个频段
  必须属于同一LAN；
- 通过串口查看`airlinkctl status`或导出`airlinkctl diag export`。

Release镜像不会开放SSH、Telnet或adbd。

## 4. CH347模式与引脚图

CH347由C906L本地控制，不等待Linux、Wi-Fi或VirtualHere。

| 圆屏模式 | 芯片模式 | 功能 |
|---|---:|---|
| 双路UART | MODE0 | 两路UART |
| SPI / I²C厂商驱动 | MODE1 | 厂商驱动SPI和I²C |
| SPI / I²C HID免驱 | MODE2 | HID免驱SPI和I²C |
| JTAG / UART | MODE3 | JTAG加UART |

进入CH347页面，点击“切换模式”，选择后确认。C906L会设置DTR1/RTS1、复位CH347
80ms并更新界面。切换会导致USB重新枚举，正在进行的VirtualHere传输可能中断。

点击“引脚对照”后，只显示当前实际模式的2×6引脚图。带“屏幕方向”文字的圆角
矩形表示靠近实体屏幕的一侧。该页面只读，点击任意位置返回，不会切换GPIO或模式。

## 5. 电池、刷新和屏保

- C906L在LVGL首帧前完成第一批ADC采样，不依赖Linux启动；
- 四格电池使用轻量滤波，短暂异常采样会保持上次结果，不会绿灰闪烁；
- 30秒无操作后进入屏保；
- 触摸、GPIOA_29稳定模式变化、手机配网成功都会重新开始完整30秒计时；
- 屏保中的第一次触摸用于退出屏保。

## 6. 常见状态含义

| 圆屏提示 | 实际含义 |
|---|---|
| 等待手机配网 | 没有保存Wi-Fi，或配网会话正在进行 |
| 正在连接Wi-Fi | 正在关联或获取DHCP地址 |
| 无线服务启动中 | Wi-Fi已连接，但VirtualHere还未监听 |
| 等待电脑连接 | TCP 7575已监听，电脑尚未稳定连接 |
| 电脑已连接 | 已建立VirtualHere客户端TCP连接 |
| 无线服务异常 | 服务连续失败并超过重试条件 |

串口诊断和恢复方法见[常见问题](troubleshooting.md)。
